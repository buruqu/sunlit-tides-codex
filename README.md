# 晴光与泡影 · Sunlit Tides for Codex

西格莉卡 × 达妮娅的 Windows Codex Desktop 独立主题，当前版本 **1.2.10**。亮色是「果园午后」，暗色默认是「夜色相依」，跟随 Codex 的外观设置切换。亮暗均可选择「背景贯穿 / 独立侧栏」：默认贯穿布局将同一背景延伸到左栏，西西立绘放大进入左栏，与右侧表情一起向右微调；娅娅立绘位于右侧并水平镜像，表情放在其左侧。立绘和表情随背景透明度融入画面，表情会避让输入框。图片预览按钮下移避开窗口关闭按钮，看图时隐藏调色板。

保留发束、风吹、泪光、飘落绿叶及启动动画窗口跟随和普通入口接入。动态自动适配 60 / 90 / 120Hz，最高绘制 120 帧。安装和运行不需要 Tessalume、Node.js 或单独安装 .NET。

**下载：** [Codex 1.2.10 与 DSH 0.1.5 安装包](https://github.com/buruqu/sunlit-tides-codex/releases/tag/v1.2.10)。DSH 版源码、构建和安装说明见 [dsh/README.md](https://github.com/buruqu/sunlit-tides-codex/blob/v1.2.10/dsh/README.md)，不包含 GPT / Dragon 启动动画。更新与验收范围见 [本次发布说明](docs/RELEASE-1.2.10.md)。

保留双侧立绘、动态表情、消息团子头像、插画侧栏、渐变文字、飘落绿叶和调色板。果园使用独立人物、发束和裙摆图层，叶间暖光缓慢变化；夜景的头发、麻花辫、衣角和流苏更明显地摆动，两人分别眨眼，地面倒影与已有星点轻微明暗变化。相册新增「夜色相依·泪光」：仅西西眼眶蓄泪、沿脸颊滑落并偶尔滴下，原版仍保留。长椅、立柱、搭肩的手和相触的双手保持固定。输入、滚动、后台及减少动态模式会暂停或回退。亮面沿用 1.2.7 的头发、发辫、衣物和呼吸实现；呼吸自然度问题仍在单独检查，本版不重新调整该参数。果园午后使用带叶脉、随风翻转的落叶，夜色相依及泪光版保留泡泡，粒子开关、数量与速度设置兼容保留。暗面西西使用夜色睡衣半身立绘和透明的 27 帧 Q 版表情，右侧娅娅使用抬手、带星环的半身立绘；夜景双人构图向中央靠拢。

## 安装

1. 安装并登录 Windows 版 Codex Desktop。本版面向 Windows 11 x64。
2. 解压 `SunlitTidesCodex-1.2.10-win-x64.zip`，双击 `Install.cmd`。已有 1.0.0 / 1.1.x / 1.2.x 可直接升级，安装器保留设置及旧版完整备份。
3. 继续使用已接入的普通桌面或开始菜单图标，名称保持不变。原生应用固定项需要重新固定这个普通快捷方式；详见 [启动入口说明](docs/ENTRYPOINTS.md)。专用「Codex · 晴光与泡影」入口仍可用。当前已有可连接的 Codex 时，会直接应用；无需退出聊天。

安装位置是 `%LOCALAPPDATA%\SunlitTidesCodex`。安装器创建自己的桌面、开始菜单和当前用户登录启动项，不需要管理员权限。托盘常驻程序在登录 Windows 时启动带主题的 Codex，后续打开窗口或登录完成后自动加载。首次加载图片可能需要数秒。

**启动边界：** 本项目通过仅限本机的调试连接加载主题。安装时仅按真实目标识别当前用户常用目录中的 Codex 快捷方式，包括指向同一 Codex 的旧 Dragon 入口，保留普通名称和图标；原始文件及哈希保存在 `data/entrypoints`。普通入口沿用主题开关，恢复默认后不会因再次打开应用而强行开启。MSIX 注册的原生固定项、直接 EXE、协议及更新程序自行重启不属于快捷方式覆盖范围，不能保证带上主题连接。程序不会强制关闭正在工作的 Codex，也不修改官方安装包。

如果旧的主题管理器仍在运行，应先关闭它，避免两套程序同时覆盖外观。已有 Tessalume 可保留作为备份，但独立版不读取其安装目录、主题库、状态或更新服务。

## Dragon 启动动画

内置原先使用的 Dragon Codex Boot 1080p 动画。常驻程序识别新启动的 Codex 主窗口后播放。1.2.6 播放器覆盖目标窗口的可见边界，随窗口移动、缩放、最大化和 DPI 变化调整；视频等比铺满，超出部分居中裁切，不拉伸角色。按钮叠在底部，窗口隐藏、最小化或关闭时播放器结束。动画结束淡出，按 **Esc** 或“跳过”立即进入 Codex。

在 Codex 的 **调色板 → 启动动画 → 以后启动 Codex 时播放龙娘动画** 调整开关；动画底部和托盘也有同一开关，选择保存在本机。调色板恢复主题参数不会改掉这一选择。

动画检测独立于主题调试连接。常驻程序退出后不检测；安装升级、切换任务、切回已打开的 Codex 不会重复播放。播放依赖 Windows 媒体组件，缺少解码能力时自动跳过。播放器只调整自身，不改变 Codex 窗口尺寸，不使用全局置顶。

## 使用与恢复默认

- 在 Codex 设置中选择亮色、暗色或跟随系统；默认背景分别是「果园午后」和「夜色相依」。在 **调色板 → 背景 → 选择背景** 打开缩略图相册，切换旧背景；亮暗模式分别记住选择。相册关闭后不占聊天区，Esc 关闭并返回入口。
- 相册中可恢复当前模式的默认背景，不影响另一种模式。本轮主要打磨这两张默认背景，其余素材保留原设计。
- 流泪效果在相册选择「夜色相依·泪光」。只有这个版本启用西西的动态泪珠，普通「夜色相依」保持原样；关闭背景动态总开关或启用减少动态时回到静态图。
- 点击界面「调色板」调整阅读宽度、透明度、立绘大小、文字渐变和动效。主题参数只保存在本机。
- 在调色板选择「背景贯穿 / 独立侧栏」；布局亮暗通用，默认贯穿。切回独立侧栏可恢复此前分区排版，其他相册和透明度偏好保留。
- 在调色板关闭「背景动态（总开关）」即可恢复静态主图；「场景光影与氛围」和「主背景人物眨眼」可单独控制。主背景在独立 Worker 中直接绘制，自动跟随原生刷新率：60 / 90 / 120Hz 分别对应最高 60 / 90 / 120 帧，144Hz 及以上限制在最高 120 帧。动画按真实时间运行，刷新率变化不会改变摆动速度。实际帧率仍受设备负载影响；主题不修改 Windows 显示设置。普通鼠标悬停不暂停动画，输入、滚动和拖拽仍会短暂停顿。
- 切换聊天时，动态画布跟随当前可见聊天页面；保留在后台的旧聊天不占用动画画布。泪光、果园与普通夜景使用同一机制，不依赖刷新整个 Codex。
- 托盘右键选择「恢复 Codex 默认外观」可停止后续注入并移除当前主题；不清除账号、聊天、项目或 Codex 原有设置。
- 再选择「启用主题」可恢复。参数会保留。
- 双击 `Restore.cmd` 也可恢复默认；`Uninstall.cmd` 恢复默认后移除本项目的程序、登录启动项及自有快捷方式。

恢复默认不会强制重启 Codex。已经启动的本机调试端口随该 Codex 进程结束；卸载后从原始入口下次冷启动不再添加此参数。

## 本版布局修复

聊天区域保留一个原生纵向滚动容器，消除主题导致的外层额外滚动条。代码块横向滚动、长输入框、设置和右侧面板保持各自滚动。项目菜单打开时，首页装饰主动让出空间，不盖住菜单项目。

## 从源码构建

构建机需要 Node.js 22+、.NET 8 SDK 和 Windows；使用者无需这些依赖。

```powershell
npm install
npm run build:theme
dotnet run --project host -- --self-test
$env:PLAYWRIGHT_EXECUTABLE_PATH = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npm run test:browser
node tests/scene-motion.cjs
node tests/worker-scene.cjs
node tests/tear-scene.cjs
node tests/scene-workspaces.cjs
node tests/scene-blending.cjs
node tests/motion-mesh.cjs
node --test tests/motion-scheduler.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Package.ps1
```

`theme/` 是可编辑的主题源码及素材，`host/` 是独立托盘宿主，`installer/` 是当前用户安装脚本。`dist/`、`release/` 和运行日志不进入 Git。构建脚本输出安装 ZIP 与 SHA-256 校验文件。开发检查和实机验证记录见 `docs/VALIDATION.md`。
