# DSH 主题验收

| 规则 | 由什么核对 |
|---|---|
| 合成页面通过不能写成真实 DSH 验收通过 | 交付记录必须区分合成测试、安装 SHA-256 和原生窗口截图或用户人工确认 |
| 原生外壳结构以本机 DSH 源码为准 | `tests/client.cjs` 使用 AppFrame 直接三列结构、晚加载暗色样式与全窗口遮挡负例 |
| 导出的客户端必须与已验证的本机文件一致 | 交付前比较 ZIP 内 `lib/client.js`、工作目录和安装目录的 SHA-256 |
| 窗口、侧栏和右栏变化不能让装饰挡住正文或输入 | `tests/client.cjs` 多尺寸、走廊几何及原生 sticky/overlay 输入区用例 |
| 渐变不能隐藏列表标记、链接、代码或状态信息 | `tests/typography.cjs` 原生文本节点、语义排除、纯色回退及缺失样式负例 |
| 贯穿背景中的立绘/GIF与壁纸只共用一次透明度，不额外挤窄正文；独立侧栏仍保留原走廊 | `tests/client.cjs` 两布局、alpha链、阅读宽度和原生按钮点击检查 |
| 仅果园落叶，夜色相依及泪光版保留泡泡；背景强度为0时果园叶子也不可见 | `tests/leaf-particles.cjs` 亮暗果园、夜景、两布局及0/35/100强度检查 |

沿用现有 DSH 插件接口；不加入 GPT 启动动画。只读检查和本插件的修复不授权改动其他插件、账号、聊天内容或权限。
