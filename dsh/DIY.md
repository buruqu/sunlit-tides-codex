# 素材与布局编辑

适用于开发候选 Codex 2.1.0、DSH 0.3.0。现有双人主题仍是默认方案；首次升级不会改变已有预设和调色板偏好。

## 入口与操作

Codex：**调色板 → 开启编辑**。

DSH：**晴光 → 开启编辑**。

调色板的预设参数即时保存。点击“开启编辑”后，画布出现拖动框，右下角可缩放；此时所有操作都是草稿。“保存并退出”提交，“取消编辑”或 Esc 放弃本次草稿。面板中的名称、位置、尺寸与画布同步。素材、布局、字体和特效分组显示，标题和操作栏固定。

按住面板顶部标题栏可在应用内移动；鼠标拖到主窗口边缘时由桌面浮动面板接续。把标题栏拖回应用内部并松手即可停靠。无需另开编辑器，同一份草稿、待确认素材和撤销历史保留。面板关闭或连接出错会返回原页面；面板内“取消编辑”仍按取消草稿处理。此能力仅面向 Windows 桌面版本，需要已安装的 WebView2 Runtime，远程浏览器继续使用页面内面板。

## 按用途快速放置

导入图片或使用素材库时，选择“素材用途”：主背景、侧栏背景、聊天区背景、输入框背景、顶部功能栏背景、左／右立绘、左／右表情、自由装饰、特效纹理。固定用途会更新同一位置，不重复叠加主背景。首次采用宿主区域与适应方式；再次换图保留位置、透明度、翻转等调整。新增预览仍可调整、取消和确认。

背景首次设置默认“跟随区域尺寸”。手动修改几何后切换为自由位置，也可以勾回跟随；背景始终位于对应区域的按钮、正文和输入框之下。功能区本身的移动在“布局”中调整。用途变更只保存到当前应用的当前亮暗方案，另一方案保持原样。

1. 在“新增素材 / 特效”填写名称，选择背景、侧栏背景、立绘、表情、普通图片或特效粒子纹理，导入 PNG、JPEG、WebP 或 GIF。
2. 新文件先进入预览，可改位置、尺寸、透明度、翻转、旋转、模糊、图层顺序和图片适应方式；“确认添加”才纳入图层列表，“取消新增”撤掉预览。
3. 自定义名称会成为图层列表和参数面板中的名称，例如“左侧立绘”。已有预设背景、侧栏、人物、表情和场景特效也列在同一列表中，可单独调整、替换、隐藏或恢复默认。
4. 侧栏、聊天区和输入框是实际功能区，可以拖动和缩放。它们保留原有内容和输入草稿，不可隐藏、删除或旋转。位置按窗口百分比保存，并留出标题栏和最小可操作尺寸。
5. “字体与文字颜色”可调整字体名称、字号、行高、纯色和两端渐变色。代码、链接、输入控件和状态信息保留语义样式；渐变不隐藏列表标记。字体名使用本机已安装字体，没有该字体时由系统回退。

## 精细调整

- 立绘、表情和普通图片默认“保持比例”。改宽、改高和拖动缩放角时，另一边按实际像素比例联动；关闭后可独立调整。旧工程保持兼容。特别狭长的图片若无法同时满足尺寸上下限，会关闭比例锁并提示，保留合法框尺寸；“完整显示”仍保持图片本身的比例。
- 选中画布素材后，方向键每次移动 1px，Shift＋方向键移动 10px；Ctrl/Cmd＋Z 撤销，Ctrl/Cmd＋Shift＋Z 或 Ctrl/Cmd＋Y 重做。输入文字或修改数字时，快捷键保留输入框自身的行为。
- “水平居中”“垂直居中”“移回画布”可快速定位，包括还没确认的新素材。移回画布会把屏幕外的素材找回；过大的素材会适当缩小。这些操作均可撤销。
- 编辑右侧素材时，可“收起面板”腾出空间，草稿和新增预览仍保留；顶部“显示面板”可重新打开。关闭按钮和 Esc 仍按取消编辑处理，不等同于收起。
- 侧栏、聊天区和输入框统一保留顶部 44px，不能拖出可操作范围。参数、选框与实际显示使用同一边界；窗口变小后的临时约束不会自动覆盖原保存布局。
- 内置立绘进入编辑时保持“完整显示”，避免误裁切人物。背景选择“完整显示”会显示原图并暂时停用原分层场景动画；切回“铺满”恢复。背景支持负坐标和最大 200% 尺寸。

## 特效编辑

**果园午后的落叶、夜色相依的泡泡只是默认预设。** 用户主动编辑时可以在任意方案中添加落叶、泡泡或自定义特效图层，也可以叠加多个特效。

- “落叶预设”“泡泡预设”都先进入可调节的新增预览。
- 导入图片/GIF并选择“特效粒子纹理”，可用自己的雪花、花瓣、星星等图片做粒子。
- 可调粒子数量、大小、速度、上下左右方向、摇摆幅度，以及整层位置、覆盖范围和透明度。
- 原生场景动画维持现有刷新策略；新增粒子由浏览器动画系统按设备刷新率合成，实际流畅度取决于设备和负载。后台暂停粒子移动；系统减少动态设置下隐藏新增粒子。

自定义粒子导入的是图片素材，不执行脚本或着色器，也不是视频壁纸/Live2D工程导入器。普通静态图不会自动获得人物发束、衣物网格动画。未修改的原预设继续使用现有精细动画；替换预设人物图后按导入图片/GIF显示。

## 保存、恢复与分享

亮色和暗色分别保存，切换外观会取消当前未保存的画布草稿。恢复默认只移除当前模式的 编辑覆盖，回到原主题及原调色板偏好；不会删除素材库。恢复上次保存可找回恢复槽中的方案。原调色板的“恢复默认”仍只管理原预设参数。

“导出分享工程”包含亮暗两套方案与导入素材，内置素材使用引用，不重复打包。Codex 和 DSH 可交换工程；两端原生功能区布局独立，导入时不强套另一宿主的侧栏、聊天区和输入框布局。开启编辑 后导入工程也是草稿，取消不会覆盖已保存的亮暗方案。

素材保存在当前应用 WebUI 的本地 IndexedDB。重新打开和普通升级保留同一应用资料中的记录，但不会自动云同步；清除应用资料、换电脑或换 WebUI 地址前，应导出工程备份。不要把只存在浏览器存储中的素材当作唯一原图备份。

每张图片最多 12 MiB，素材库最多 60 MiB；单边最多 16,384 px、总像素最多 6,400 万；工程最多 200 图层/素材、JSON 最多 85 MiB。超限或格式错误会明确拒绝，并保留原保存方案。SVG、远程 URL 和脚本不作为用户素材执行。

删除图层或取消新增不会立刻删除库中的文件。“清理未使用素材”只清理完全无引用的文件，保护两平台亮暗方案、恢复槽、草稿、撤销历史和其他活动窗口。仍被引用的文件不会清理；清理后可重新从原文件导入。

## 兼容边界

该功能使用现有主题注入接口，没有修改官方程序、账号、模型、权限或聊天记录。功能区定位依赖宿主界面结构，宿主更新后可能需要重新适配。当前自动化及浏览器工具验收使用真实构建包和合成宿主页面；安装到本机后的原生窗口效果须另行验收。

DSH 不包含 Codex 的龙娘启动视频。
