# 晴光与泡影 1.1.2

修正暗色西西动态表情的白色底板，换上指定的娅娅半身立绘，并将双人夜景向画面中央调整。

- 西西 GIF 原本自带透明区域，移除额外 CSS 白底、圆角与阴影；保留原始 27 帧、每帧 60ms 的动作。
- 右侧使用 DSH 原版抬手、带星环的娅娅半身立绘，原图未重编码或翻转。
- 夜景使用原图等比缩放和响应式取景，覆盖完整主区；人物向中间靠拢，头脸保持完整。
- 亮色果园、消息团子、启动动画和已有调色板设置保留。
- 支持从 1.0.0 / 1.1.0 / 1.1.1 升级并完整备份旧版。

Windows x64：解压后运行 `Install.cmd`；`Restore.cmd` 恢复默认外观。
