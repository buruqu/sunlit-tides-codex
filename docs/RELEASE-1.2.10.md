# 晴光与泡影：Codex 1.2.10 / DSH 0.1.5

本次联合发布保存当前两套主题的源码和可安装版本。Codex 源码位于仓库根目录，DSH 位于 `dsh/`；两端独立构建、独立安装。

## 外观与布局

- 亮色「果园午后」和暗色「夜色相依」均支持背景贯穿左栏，也可在调色板切回独立侧栏。
- 贯穿布局中的西西立绘进入左栏，立绘和右侧表情整体向右移动约 28px；娅娅立绘位于右侧并水平镜像，表情放在其左侧且保持原方向。
- 立绘和表情只应用一次背景透明度，不因装饰额外挤窄正文。窄窗口中表情会避开输入框；空间足够时保持底部排布。
- 保留亮暗文字渐变、头发和衣物摆动、眨眼、光影与可选西西泪光。仅果园使用飘落绿叶；普通夜景与泪光夜景保持泡泡。
- 动画按时间推进，适配 60 / 90 / 120Hz，上限 120fps；实际帧率取决于显示器和设备负载。
- Codex 图片预览工具栏避开 Windows 窗口控制按钮，看图时隐藏主题调色板。保留 Codex 启动动画窗口跟随和普通入口接入；DSH 不包含 GPT / Dragon 启动动画。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `SunlitTidesCodex-1.2.10-win-x64.zip` | Windows x64 Codex 安装包；解压后运行 `Install.cmd` |
| `SunlitTides-DSH-0.1.5.zip` | DSH 皮肤安装包；正常退出 DSH 后运行 `installer/Install.ps1` |
| `SunlitTides-DSH-source-0.1.5.zip` | 自包含的 DSH 源码及已构建客户端 |
| `SHA256SUMS.txt` | 上述 ZIP 的 SHA-256 校验值 |

Codex 升级保留主题设置和旧版完整备份，不修改官方应用包。DSH 安装器通过官方 CLI 注册独立皮肤，保留 profile 备份；恢复时会检查后续配置改动。请分别阅读根目录和 `dsh/` 的安装与恢复说明。

## 验证证据与边界

交付阶段已完成 Codex 17 项和 DSH 22 项布局检查，浏览器错误为 0。覆盖亮暗、多窗口尺寸、输入框避让、阅读宽度、布局切换与卸载清理。Codex 图片预览另有 21 项专项检查，覆盖两类预览结构、缩放、关闭点击、Esc 和恢复。

Codex 构建版本契约 4 项、升级隔离检查 27 项通过；DSH 已构建客户端通过真实 ModuleLoader 接口、Worker、重复挂载和清理检查。两端已安装的受管运行文件与对应安装 ZIP 的 SHA-256 一致。发布整理只调整文档、预览和 DSH 打包默认目录，没有重新调整动画参数。

README 展示的是实际主题包在合成界面中的浏览器截图，不是原生应用截图。原生窗口截图工具超时，未取得当前版本的原生像素验收证据。较早版本的人工确认不作为当前版本的确认。亮面胸口局部呼吸自然度仍单独检查；本版保留已有参数，不宣称这一问题已经修复。

当前适配环境是 Windows Codex Desktop 与 DSH 0.2.1-rc.3；未将本次证据推广到所有未来版本或远程 Web 部署。Codex 原生应用固定项、直接 EXE、协议和应用更新自行重启不保证带上主题连接，详见 [启动入口说明](ENTRYPOINTS.md)。
