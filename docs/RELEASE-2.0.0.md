# Codex 2.0.0 / DSH 0.2.0 — DIY 编辑器候选

状态：已完成开发与隔离验证，准备更新包；尚未安装本机或发布 GitHub。此前公开版本仍为 Codex 1.2.11 / DSH 0.1.6。

两端原调色板新增共享“素材与布局”编辑器。背景、侧栏背景、立绘、表情、图片与特效支持命名、导入、画布拖动/缩放和参数同步；新增素材先预览调整，再确认添加。侧栏、聊天区、输入框可直接移动和缩放，保留原生操作与输入草稿。

落叶和泡泡成为可复用的特效预设，自定义图片/GIF可以作为粒子纹理。果园默认落叶、夜景默认泡泡保持不变，用户主动添加时不受该预设对应关系限制。支持字体、字号、行高、颜色、渐变；支持撤销/重做、取消、保存、恢复默认、工程导入/导出与安全清理未使用素材。

使用与限制见 [DIY 说明](DIY.md)。默认未修改场景继续使用原有动画，未重调呼吸自然度参数。

- DSH：适配器与实际构建完整 UI 集成通过；原界面 22 组、字体 7 组、落叶 11 组及真实 ModuleLoader 包加载检查通过。
- 浏览器工具实际操作新增右侧泡泡、确认、保存、刷新并打开参数，位置 70%、宽度 30%、透明度 45%、粒子 12、速度 1.5 均保留，控制台错误 0。

## 更新影响与恢复

Codex 安装器支持从 1.2.11 升级并备份受管主题。只切换主题辅助程序，不重启 Codex 主程序；已连接窗口可重新应用主题。DSH 安装器要求正常退出 DSH 后更新该插件，注册完成后从原入口打开；不自动强制终止聊天。

发布执行前刷新实际版本、进程和候选哈希；Codex 使用安装包 Install.cmd，DSH 使用包内 installer/Install.ps1 和实际 CLI 路径。安装失败保留/恢复原文件；正常安装后的 DSH 回退使用本次备份记录和 Restore.ps1，Codex 外观恢复使用 Restore.cmd，回旧版使用保留的完整安装备份。工程数据在应用资料中，更新文件与清理工程是不同操作。

此次交付只准备更新包及操作说明，按用户下一次更新/发布指令执行安装和原生验收。
