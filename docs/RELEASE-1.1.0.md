# 晴光与泡影 1.1.0

整合 Dragon 启动动画，保留果园午后与昭日遇见暗潮两套主题。

- 常驻程序识别正常启动的 Codex 主窗口，无需单独龙娘快捷方式。
- 调色板、播放窗口与托盘共享“以后播放”开关，设置持久保存。
- Esc / 跳过立即结束；动画结束淡出，不改变 Codex 窗口大小。
- 从 1.0.0 升级时保留设置，完整旧目录作为可恢复备份。
- 保留单聊天滚动区和原生项目菜单避让修复。

下载并解压 Windows x64 ZIP，运行 `Install.cmd`。`Restore.cmd` 恢复默认主题，`Uninstall.cmd` 卸载。ZIP 的 SHA-256 校验文件一并提供。

宿主需保持运行；切回已经打开的 Codex 不重复播放。原生入口冷启动可能缺少主题调试连接，可从“Codex · 晴光与泡影”打开；启动动画不依赖该连接。媒体版权与代码许可分开，见根目录 NOTICE 与 media/MEDIA_NOTICE。
