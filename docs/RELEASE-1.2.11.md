# Codex 1.2.11 / DSH 0.1.6

- 贯穿布局中的西西立绘和表情包在上一版基础上整体再向右移动约 24px；两侧表情包靠近输入框时上移避让，正文宽度保持原值。
- 非果园场景最右侧补充少量错时升起的小泡泡，复用粒子数量设置，保留完整圆形轮廓。果园午后无论亮暗模式都只保留叶子，不新增泡泡。
- 调色板新增「立绘透明度」「表情包透明度」两个独立滑块，0% 隐藏，100% 完全显示。默认仍跟随背景；手动调节后不再受背景透明度限制，亮暗模式分别保存，点击相应「跟随背景」按钮可恢复。

Codex 在调色板的「角色」中调整；DSH 在「✦ 晴光」调色板中调整。旧设置自动兼容，不修改聊天、账号或模型配置。DSH 不含 GPT 启动动画。
