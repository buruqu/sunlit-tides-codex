# Codex 2.0.2 · 主题入口图标

把用户选定的「暖阳 + 蓝紫泡泡 + GPT 标志」图标正式纳入 Windows 宿主和安装包。

- 启动程序嵌入 16–256 像素的多尺寸透明图标，托盘也从程序自身读取图标。
- 桌面和开始菜单的专用主题入口使用安装目录内的稳定图标路径；普通 Codex 入口继续保留原图标。
- 安装器随包复制并校验品牌图标，支持从 2.0.1 升级，保留原设置和完整旧版备份。
- 背景、人物、动画、DIY 工程格式和 DSH 0.2.1 均保持原行为。

本补丁包为 `SunlitTidesCodex-2.0.2-win-x64.zip`，解压后运行 `Install.cmd`。需要恢复 Codex 默认外观时运行同一包的 `Restore.cmd`；它不会回退主题程序版本。主题辅助程序会短暂重新连接；不需要重启 Codex 主程序。

图标原稿、编辑提示和来源说明见 [图标说明](../assets/branding/README.md)。GPT 标志用于识别对应启动入口，本主题仍为独立社区项目。

本批先提供本地安装包；GitHub 已发布版本和链接仍为 v2.0.1，不把尚未发布的下载地址写成可用链接。
