# Codex 2.1.0 / DSH 0.3.0 联合发行

本版增加可拖出、可拖回的同一调色板／编辑面板，并提供按素材用途快速替换。包含 Codex 2.0.2 的已选入口图标；没有修改原预设动画参数，也没有为 DSH 加入启动视频。

## 下载

联合标签：[v2.1.0](https://github.com/buruqu/sunlit-tides-studio/releases/tag/v2.1.0)。三个发行资产：

- [Codex Windows x64 2.1.0](https://github.com/buruqu/sunlit-tides-studio/releases/download/v2.1.0/SunlitTidesCodex-2.1.0-win-x64.zip)
- [DSH 插件 0.3.0](https://github.com/buruqu/sunlit-tides-studio/releases/download/v2.1.0/SunlitTides-DSH-0.3.0.zip)
- [DSH 独立源码 0.3.0](https://github.com/buruqu/sunlit-tides-studio/releases/download/v2.1.0/SunlitTides-DSH-source-0.3.0.zip)

独立源码包含原生载体源码及构建资源；运行包包含所需载体，不需要用户单独启动主题服务。安装与恢复步骤见 [安装指南](INSTALL.md)。

## 变化

- 标题栏在应用内拖动，越过边缘时由受管 Windows WebView2 面板承接，拖回应用内停靠。原页面持有草稿、撤销、已选图层和素材库；面板只同步控件，不再创建第二个编辑会话。
- 删除重复的“素材与 DIY”入口，用户界面统一为“开启编辑”。面板不透出壁纸；固定标题、操作栏及分组减少拥挤。
- 按主背景、侧栏背景、聊天区／输入框／顶部功能栏背景、左右立绘／表情放置；固定用途不叠加重复层，换图保留调整。自由装饰与特效仍可多层叠加。
- “跟随区域尺寸”使区域背景随布局和窗口变化；关闭后可自由编辑几何。
- 旧工程 ID、IndexedDB 和技术包名保持兼容。当前亮暗方案分别保存。
- 合入 2.0.2 的多尺寸透明入口图标：程序、托盘和专用主题入口使用用户选定图标；普通 Codex 入口保留原有图标。版权和媒体再分发限制继续适用。

## 桌面能力与限制

Windows 面板使用 Microsoft WebView2 SDK 1.0.3650.58 和机器已有 WebView2 Runtime。缺失运行时或桥接不可用时，原面板与草稿留在应用内并提示；安装包不自动下载运行时。DSH 通过官方插件 Connection RPC 启动受管辅助程序，不修补官方应用。

验证分为实际构建包在合成宿主中的浏览器流程、真实 WinForms/WebView2 隔离拖动与事件回传、文件及安装载荷校验。这些隔离结果不构成实际 Codex／DSH 宿主验收；实际宿主完整流程、多显示器不同 DPI 和长时间编辑仍需另行验收；本说明不将隔离测试写成实际宿主已通过。逐项结果见 [本版验证记录](VALIDATION-2.1.0.md)。

## 更新与恢复

安装与上传由本批执行指令控制；本说明记录发行内容及验证边界，不代替实际部署记录。Codex 更新只替换本主题辅助程序与受管文件，不重启 Codex 主程序；DSH 插件更新需要先等任务完成，再正常完全退出 DSH。使用已有安装器和恢复脚本，保留原设置、素材库与完整恢复点。

安装执行建议预留 10 分钟，其中前 6 分钟用于安装和初验、后 4 分钟用于恢复；这是预估，实际启动耗时取决于本机。若安装阶段失败，安装器恢复受管目录并保留证据；若安装后验收失败，Codex 先通过 Restore.cmd 恢复官方默认外观，DSH 通过本次恢复点恢复旧插件和配置。Restore.cmd 不是 Codex 旧版本文件回滚器，旧目录保留待核验；不回滚聊天、用户工程或素材数据库。若用户明确要求全部完成后再恢复使用，则按该模式处理。
