## 验证边界

本次安装已核对 Codex 2.1.0 的 10 个受管文件与发行载荷一致，原设置摘要及原 Codex 进程保持不变。实际 Codex 页面已通过调色板入口、开启编辑、素材用途选项及取消后保留原方案四项交互检查；此结果不包含外部面板连续拖动或多显示器验收。DSH 安装结果另按实际部署记录核对。

合成宿主中的浏览器通过、隔离 WebView2 原生窗口通过、安装文件一致性，是三类独立证据；它们不等于实际 Codex / DSH 的整套操作已验收。实际部署状态应以当次安装记录为准，本记录不预先宣称实际宿主中的跨进程拖动、文件导入和保存/取消均已通过。

不同 DPI 的多显示器拖动、其他宿主版本和长时间编辑尚未完成验证。外部面板依赖机器已有的 Windows WebView2 Runtime；缺失或连接失败时回到应用内编辑并保留草稿，不自动下载运行时。预设呼吸自然度仍有独立待检查项，本版沿用原参数。

本次发行保留技术包名、旧数据键、历史版权署名和媒体限制，详见 [NOTICE](../NOTICE.md)、[素材记录](ASSETS.md) 与 [安装恢复说明](INSTALL.md)。
