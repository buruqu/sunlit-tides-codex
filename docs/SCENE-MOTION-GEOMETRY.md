# 场景动作与几何边界

夜景以`manifest.assets[scenes.night.sourceAsset]` 对应的源图 的 1272×847 坐标为基准。机器可读参数在 `theme/design/night-motion-spec.json`；对象可直接嵌入 `scenes.night`。眼部中心和半径归一化，其余路径、边界、锚点和半径为原图像素。旋转为角度，周期为秒，相位为弧度。

画面保持原有构图。西西和丫丫的头、躯干、肩、手及腿固定，特别是丫丫搭在西西肩上的红手套。长椅、立柱、地面反射的形状与透视固定。人物的动作包括自由发束、衣角、袖口及流苏的轻摆，以及两组独立眨眼；每组的左右眼必须同时闭合，不能让四只眼逐个随机闪动。

生成闭眼图缩放到原图尺寸后，西西闭眼线比原眼中心略低。因此西西两眼使用绝对像素 `sampleCenter: [534,252] / [601,253]`，仅将闭眼图的采样位置向下配准 4 像素，让闭眼线落入原眼部蒙版内圈。原图上的 `center`、`radius` 与眼周蒙版保持不变；这不是移动眼睛或脸部。丫丫继续同坐标采样。

原六个有物理依据的自由区域包括：西西左下橙发末端、丫丫右上独立发丝、左侧披衣底部紫白衣角、右侧悬垂流苏，以及新增的丫丫较长粉发自由束和垂落袖口。粉发自由束沿 x1118–1185、y321–499 的弧形轮廓，袖口沿 x1126–1198、y584–685 的衣料折线。金色系带的上方固定点、紫色发辫蝴蝶结及衣物的身体接触点留在静态图层。左侧披衣片保持 x307–405、y690–768 的下缘弧形区域，避开腿和 x304、y743 附近的金色绳结。

1.2.3 按用户明确要求进一步提高可见动作。夜景原六片 rotation 分别为 34、36、36、32、18、32 度，周期 4.0–5.2 秒；这不是实际刚体转角。波形仍是 `(sin(time * 2π / period + phase) - sin(phase)) / 2`，phase 为零，并继续乘半径渐变和固定根段权重。主要长粉发末端单侧约 25 源像素，袖口约 23，右上发丝约 21，左披衣约 13；小橙发与流苏约 14 / 11。两极之间的摆程约为上述数值的两倍，单侧几何检查上限为 32 源像素。`motionTip` 均为原轮廓内真实末端，不能用空透明角落证明幅度。

1.2.3 另将西西左侧两枚橙色辫球及中间金箍作为一段真实原像素发段，顶部披肩接触线和底部紫色蝴蝶结均锁定，中间自由边约20–22源像素（motionTip为原发球内的[339,570]），根部渐变带64px以避免大角度在窄固定带附近翻折网格。不能只选辫球内部而把橙色描边留在静态图里；完整发球轮廓必须进入同一所有权，发圈中的背景孔保留固定。新增大辫外缘覆盖2px抗锯齿带，娅娅长发覆盖1.5px，mesh bounds同步包含扩边；小孔另用fixedHoles保留固定背景。补底seed仅在这两片轮廓之外额外排除4px，防止把边缘残留发色和孔口混色当作底纹放射回填；此seed排除带不改变合成所有权或t0。

渲染默认在独立 Worker 内直接驱动 OffscreenCanvas，目标上限为 120Hz，仍只使用真实 Worker RAF。60 / 90 / 120Hz 原生 RAF 会各自绘制 60 / 90 / 120 帧，144Hz 及以上由 deadline 分布限制在约 120 帧；不使用忙循环或重复旧图冒充高帧。deadline容差1.25ms覆盖相邻RAF时间戳交替±0.6ms的浮点/调度抖动，deadline仍在120Hz理想栅格推进；重复时间戳不重复绘制。`targetFps`、`observedRafHz` 和 `measuredFps` 分别报告目标、原生 RAF 供给与真实绘制。兼容字段 `missedFrameSlots` / `deadlineSlotsSkipped` 表示未获得原生 RAF 的目标时隙，不等于显示器实际掉帧；例如 60Hz 显示器上目标为 120 时该值自然增长。
夜景 8px 网格使用至少 14px 的完全锁定带，覆盖跨过切缝的整个三角形及 3×3 检查邻域，避免只在解析线上为零、三角插值却漂移。果园 12px 网格相应用 20px 完全锁定带。`rootSegments` 标记内部切缝，`anchorFade` 表达切缝附近回落到零位移的像素宽度。长粉发和袖口根段在24–25px范围渐隐，披衣为28px，新大辫为64px，避免多固定点附近的三角形翻折，左披衣靠近金绳的 x307、y743–758 边缘另保持固定，肩、手套、腿及身体不随之移动。切缝不以模糊整图掩盖。较大粉发和袖口应在正常显示尺寸下看得见，而不能只靠诊断上限证明“有动画”。

静态原图必须扣除与动作图层完全相同的所有权遮罩，原像素只能出现一次。静态原图扣除的孔后方放专用补底，补底只在遮挡揭开时可见。本版使用 `underfillMode: boundary-extend`、`underfillPixels: 40`：从所有动作所有权之外的相邻原图像素向孔内延展最多 40 像素，深孔继续用已有 cleanplate。初始化用两遍可分离欧氏距离变换得到精确最近固定像素；复杂度随整图像素线性增长，半径扩大不增加每像素候选穷举。延展不改孔外像素，也不把原发束复制到下面。新增粉发内侧遮住蓝色星空披带，内缘应延展披带纹理，外缘应延展地面；不能让地面 cleanplate 在蓝披带边缘形成裂缝。袖口同理延展相邻固定衣料。矩形边界仅供调试，不得拿矩形直接裁切替代实际曲线路径。

灯光只改变局部颜色与亮度，几何位移始终为零。暖色变化落在左侧地面反射，亮度差上限 0.115；右侧已有发丝和星点高光的冷光上限 0.10，并保持 highlightOnly。它们应在正常尺寸可察觉，但静止时间零位仍是零增量。“场景光影与氛围”开关必须同时关闭这两种变化。立柱、椅背与椅座不能因灯光掩码产生折弯或类似水面波纹的错觉。禁止整图波浪、整图浮动、全身呼吸拉伸或移动手套。

果园沿用已经存在的分层图和轮廓，不重新切人物。其主要发/衣末端单侧约 23–34 源像素，双端接续的中辫在中部弯动约 13。原 root PNG 的各连通切缝提取为固定根段，20px 锁定带外再用28px渐隐，粉发middle单独用44px以消除增幅后的内部三角翻折，双端接续的中辫、粉发和裙摆两端都固定；中辫的下接缝与低辫根段相同。身体平移归零，避免盖片及接触点随身体移动。源图原本延伸到画框外的片，仅在画外延伸 48px 网格并钳制原边缘采样，防止把裁切边旋进画面；这不改变摄像机或画内坐标。运行时用原 PNG alpha 作为所有权，在 parent body 孔内延伸最多 40px 的邻近固定原图纹理；不把移动片复制回静态孔。既有果园中段发辫、自由粉发和裙摆仅在具有对应补底时启用；不把前景树枝、水果、篮子、肩颈、手臂和身体一起摆动。两种场景共享“固定人物支点、自由末端轻摆、局部光色变化”的原则。

验收时显示实际路径的半透明覆盖图，确认选区里没有木板、地面、皮肤或另一人物。分别检查零位和动作两端；零位应与原图一致，动作极值不能出现静态残留、双重边缘、空洞或上下半片断开。先关闭灯光和眨眼，记录每片实际末梢位移与整幅差异，主要夜景自由端约 20–25 源像素（较短橙发约14、流苏约11），果园自由端约23–34、中辫中部约13，并提供正常显示尺寸的极值成对截图，确认比 1.2.0 明显。再打开光照看氛围。规格列有立柱、空椅面、椅前缘、肩上手套、相触双手及衣身锚点的固定检查区。灯光开启时允许亮度差异，不能把颜色变化误判为几何移动。

这些是人工保守描边；极细发丝及抗锯齿边缘仍需看实际合成预览。宁可缩小或关闭一片，也不能把接触点、木板或身体带入动作。眨眼素材需保持眉毛、鼻子与面部明暗，只在指定眼周覆盖闭眼线；闭眼帧本身不应改变脸型和头部位置。


主界面保留多份聊天 DOM 时，isConnected 不能证明画布宿主可见。renderer 在布局/事件刷新时通过共享 resolveFusionLayout 选取实际可见 main，无共享解析器时筛选可见且非零尺寸的 main；订阅 main-surface-change 事件，宿主变化时释放旧 Worker 后挂到新宿主，所有 main 隐藏时释放并等待恢复。动画帧内不读取布局。此前切图长时间等不到画布的实机现象已确认包含隐藏旧 main 误选，不能仅归因于补底计算；距离场优化解决的是独立存在的初始化搜索开销。


## 1.2.4 局部轻摆

在原7片夜景大动作之外新增6片：西西脸侧两条细辫的中段（脸端和白bow端均固定）、娅娅两处真实螺旋末圈、西西侧刘海自由尖与娅娅冠左游离wisp。夜景没有独立可见的帽顶呆毛，因此不移动帽子或虚构新发丝。新片网格4px、根锁8px，单侧约2.7–4.8源像素。果园对应两条自由发尾、两螺旋尾、真ahoge和外侧刘海尖，另两片左缘实叶；原13片大动作参数不因新增而重设。

同一GPU后端支持foliage，与发/衣共享源空间柔性网格；每片meshStep可配置，最小安全根锁至少ceil(sqrt(2)*meshStep+2)。配置上限40层；getState.layerMeshes公开真实meshStep，新增片以motionClass=detail和tipBudget标明轻摆预算。蒙版提取、色相筛选和补底只在初始化执行，稳态不加布局读取、不建第二动画循环，保留真实Worker RAF60/90/120Hz调度。


## 1.2.5 同阵轻风与分段响应

本轮只调整27个既有活动片的时间规律，没有重描蒙版、修改原图或增加分层。共享轻风由有界的调频正弦给出：主周期5.35秒，叠加11.7/3.7秒的小相位扰动，信号始终在[-1,1]。每片以凸组合混入少量自身周期；人物自由衣角/袖口分别有9.7/11.3秒的轻缓衣料节律和略不同的响应延迟。身体平移仍为零，living-scene继续只控制眨眼，没有新增胸廓呼吸、脸部或全身缩放。

旧13个大摆动片的空间延迟为零：root/mid/tip三个时间系数相等，原有固定根、空间权重与角度范围完整保留；危险旧披衣不叠加新的空间扭曲。新增14个细部才使用0.12–0.24秒的分段延迟：root、中段、末段分别采样同一股风，在径向progress的0、0.5、1处生成三个float32系数，再通过两段smoothstep插值。progress是距pivot的径向归一化，不是真实沿辫子的弧长骨链；完全锁定的根带仍乘零位移，双端接续点不被移走。螺旋尾以正系数的较早风样本混合出柔和回摆，不做负系数超调，也没有逐帧弹簧积分。

启动包络只使用未延迟的全局time，t0处全部系数严格为零；夜景原波幅界仍为0.5、果园为1。绝对时间解析计算没有累计状态，暂停、不同原生刷新率、重复或乱序seek不会改变同时间的坐标。CPU的sunlitSceneMotionCoefficients生成与GPU完全相同的float32三系数；sunlitSceneMotionWave和sunlitSceneVertexAt复用同一插值及固定根公式，后者对任意源点返回[x,y,angleRadians,spatialWave]。GLSL直接消费三系数uniform，不另写一套正弦公式。Worker.toString包含全部共享helper，不新增动画循环或每帧DOM量测。

共同风指时间和强弱关联，不能把它宣称为全部自由端水平同向或完整空气动力学。方向符号按真实自由点相对pivot的朝向选择，多数下垂发束、衣角与上翘叶片在同一风脉冲下有一致的水平响应；夜景night-yaya-free-upper-wisp几乎水平，tip−pivot约[69,7]，保留其原圆弧约束时主要上下摆动，大角度cos收缩允许X略向内（样例约[-0.98,-20.54]源像素）。本轮明确保留这个方向例外，不为强行横移而修改pivot、根、mask或幅度。这是分层2D的惯性外观近似，不能称为真实弹簧物理或完整Live2D骨骼。

源级验证覆盖了两段64秒时窗的非固定单频特征、层间相关性、细部的真实分段延迟、绝对时间确定性及raw/normalized一致性；27片网格的保守系数与实际时间采样均保持正Jacobian，旧大摆幅预算未降低。最终GPU顶点、像素、默认Worker与宿主集成仍以统一构建的验收报告为准。
